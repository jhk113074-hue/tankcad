⚡ DWG 변환 및 다운로드 안내

웹 브라우저는 보안 정책상 고객님 PC의 프로그램을 임의로 직접 실행할 수 없습니다.
이미 ODA 변환기를 설치하셨다면, 로컬 변환 서비스(python server.py)가 실행 중일 때 웹과 연결되어 즉시 .dwg로 변환됩니다.

💡 가장 간편한 추천 방법: [DXF 다운로드]
아래 [DXF 파일로 즉시 다운로드]를 누르시면 별도 설치나 서버 실행 없이 바로 다운로드되며, AutoCAD, ZWCAD, 캐디안 등에서 DWG와 100% 동일하게 즉시 열리고 편집/저장됩니다!

🧩 판넬 등록 및 형상 편집

📦 3D STP / STEP 파일 로딩 3D CAD (.stp, .step)

SolidWorks, Inventor, Creo 등에서 제작한 판넬 3D 모델(.stp, .step)을 선택하세요.
시스템이 3D 모델에서 가로×세로 규격(W×H)과 정면 형상(외곽선, 엠보싱, 리브)을 자동 추출하여 2D 승인도면에 완벽히 매핑합니다.

AutoCAD/GstarCAD에서 작성한 단일 판넬 DWG 또는 DXF 파일을 선택하세요. 내부 선/원/호가 자동으로 추출됩니다.
